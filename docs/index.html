MintGuard

A mint-safety verification agent for .ai Agent IDs on BSC. Give it a mint contract and it checks, live: is the contract real and source-verified, is the mint open or paused, what is the exact mint price, is supply capped, is the owner renounced — and whether the project's X account exists. It answers GO / CAUTION / BLOCK with evidence for every check.

This page runs the whole agent in your browser (no server, no wallet, no signing). It reads only public data: BSC public RPC, Sourcify v2, and the project's X profile page. A check that cannot be performed is reported as unknown, never as clean. The same logic also runs as a Node server — see the repo.

How it works

MintGuard runs 10+ live probes per mint and scores them into a verdict (GO ≥ 85, CAUTION 55–84, BLOCK < 55 or any hard block). Hard blocks: no code at the address, contract paused, listed price ≠ contract price, sale closed, mint gated, or the linked X account does not exist. Every verdict is reproducible from the pinned block in the response. Read-only: it never signs, never spends, never touches a wallet.
